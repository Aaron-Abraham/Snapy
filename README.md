# Snapy - Neon Lofi Snake Game 🐍✨

Snapy is a premium, modern take on the classic Snake game, built with React and Vite. It features a cyber-punk aesthetic with glass-morphism, neon glow effects, and calming background lofi music.

## Features
*   **Endless Gameplay**: The game goes on forever until you crash into yourself.
*   **Dynamic Speed**: The snake gets slightly faster every time you eat a gem, increasing the challenge.
*   **Scoring System**: Earn 10 points for every gem eaten, with your highest score saved locally in your browser.
*   **Neon Aesthetics**: Smooth CSS gradients, glass panels, and cyber-punk inspired styling.
*   **Background Lofi**: Built-in toggle to play royalty-free relaxing lofi beats while you game.

## How to Play
1.  Clone this repository.
2.  Navigate to the `snapy-game` directory.
3.  Run `npm install` to install dependencies.
4.  Run `npm run dev` to start the local server.
5.  Open the local link in your browser.
6.  Use **Arrow Keys** or **W A S D** to control the snake.

Enjoy!
